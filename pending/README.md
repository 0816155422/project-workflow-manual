# Pending Memory Queue

วางไฟล์ที่เสนอให้เพิ่มใน shared memory ไว้ในโฟลเดอร์นี้ก่อนอนุมัติ

## ขั้นตอน
1. เพิ่มไฟล์ Markdown, JSON หรือ TXT ที่ไม่เปิดเผยข้อมูลลับไว้ใน `pending/`
2. ให้ผู้ดูแลตรวจสอบความถูกต้อง แหล่งที่มา ความเป็นส่วนตัว และความจำเป็น
3. ผู้ดูแลเปิด GitHub Actions → **Sync Approved Memory** และระบุ source path กับ destination path ใต้ `shared/`
4. การกด Run workflow ถือเป็นการอนุมัติอย่างชัดเจน ระบบจะปฏิเสธปลายทางที่มีไฟล์อยู่แล้ว
5. ตรวจสอบ `logs/approval-log.md` และประวัติ commit หลังรัน

ห้ามใส่ token, API key, password, credential, ข้อมูลสุขภาพ/การเงินส่วนบุคคล หรือข้อมูลอ่อนไหวลงในคิวนี้

> การตรวจจับ secret เป็นเพียง heuristic ไม่ใช่การรับประกันว่าไฟล์ปลอดภัย ผู้ดูแลต้องตรวจเนื้อหาด้วยตนเองก่อนอนุมัติ
