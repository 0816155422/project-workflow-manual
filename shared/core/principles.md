# Principles

**Status:** PROPOSED

- Human approval controls shared memory.
- Use repository files as source of truth only for explicitly approved project knowledge.
- AI output remains a draft until reviewed.
- Never automatically import previous chats or hidden platform memory.
- Give each platform only the files needed for the current task.
- Preserve provenance and history.
- Never commit secrets or sensitive personal data.
- Verify every write by reading it back.
- A Git repository is versioned document storage, not a real-time database.
