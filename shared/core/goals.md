# Goals

**Status:** PROPOSED — confirm with repository owner before treating as approved.

1. Provide a version-controlled shared knowledge source for AI-assisted projects.
2. Let users switch AI platforms without relying on private chat history as source of truth.
3. Separate approved shared knowledge, platform snapshots, private data, drafts, logs, and archives.
4. Preserve provenance, approvals, decision history, and change traceability.
5. Use hap-aicc/index.html as dashboard entry point.
6. Prefer reviewed Git changes over a live database unless a documented need justifies otherwise.
