# Constraints

**Status:** PROPOSED

- Never commit tokens, API keys, passwords, credentials, private keys, cookies, or sensitive personal information.
- Keep private files outside Git; private/ is not secure storage.
- Never claim write, approval, sync, or deployment succeeded without verifiable evidence.
- Do not automatically import chat histories.
- AI cannot approve its own proposed memory.
- Do not treat snapshots or archives as current facts without review.
- Avoid transient/high-frequency data that belongs in a separately approved database.
- Public repository contents may be visible to everyone.
