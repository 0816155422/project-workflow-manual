# Project Scope

## In scope
- Versioned approved shared memory and knowledge documents
- Pending review queue
- Validation and manual approval workflows
- Audit trail for approved sync actions
- Static read-only dashboard and platform-specific snapshots

## Out of scope
- Live database behavior
- Direct browser writes to the repository
- Automatic import of chat history
- Storage of secrets or sensitive personal data
- Guaranteeing safety through pattern scanning alone
