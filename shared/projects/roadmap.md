# Roadmap

**Status:** PROPOSED

## Phase 1 — Foundation
- [ ] Review and approve memory manifest and privacy policy.
- [ ] Establish status/provenance conventions.
- [ ] Confirm .gitignore excludes local private data.
- [ ] Ensure no secrets are tracked.

## Phase 2 — Templates
- [ ] Review platform templates.
- [ ] Create dated snapshots only when explicitly requested.
- [ ] Treat prompt exports as task bundles, not hidden long-term memory.

## Phase 3 — Governance
- [ ] Require human review for shared-memory changes.
- [ ] Record important decisions and approvals.
- [ ] Verify writes with read-back and Git history.

## Phase 4 — Dashboard
- [ ] Link to approved files and platform templates.
- [ ] Keep dashboard read-only unless an authenticated write path is separately reviewed.
- [ ] Test published Pages URL before claiming availability.

## Phase 5 — Operations
- [ ] Review privacy policy and stale memory regularly.
- [ ] Archive superseded documents without deleting relevant history.
